# SISEPP — demo de portafolio

Proyecto de portafolio inspirado en un caso de seguimiento de planes de inversión pública.

> **Proyecto de portafolio con datos ficticios.** No está afiliado a ninguna entidad. Licencia MIT.

| Carpeta | Contenido |
|---|---|
| [`backend/`](backend/README.md) | API REST: Java 17, Spring Boot 3.3, PostgreSQL, Flyway, JWT |
| [`frontend/`](frontend/README.md) | SPA: React 18, TypeScript, Vite, CSS con design tokens |

Ambos tienen su propio README con instalación y uso. Las credenciales y secretos no están en el repositorio: se definen por variables de entorno (ver `backend/.env.piloto.example`).
